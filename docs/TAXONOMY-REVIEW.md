# Unified collection review

The source collection and original image archive now share one selectable hierarchy:
**Superfamily → Family → Type → Subtype**. Granularity changes the grouping level of the landing cards, not image quality. Expand a branch with +, select its name to filter, or select a card to drill down. Breadcrumbs and Reset filters return to broader views. Search and collection filters work across the same hierarchy.

There are **319 references**: 72 nonmerged source records and all 247 archive groups. The complete 73 source records remain in canonical content, including the pre-existing redirected record. Eight editorial superfamilies cover all references. Original category names, prompts and credits are unchanged. Classification does not claim creative ancestry or identical prompts.

## Duplicate review

Environmental sports Series 1 and 2 are distinct source URLs with unverified prompt/image association. Their nine-image shared sample pool is displayed as one card with two source links. Neither source was erased or falsely merged.

One repeated “Below the Surface” artwork was confirmed in two paper-cut source collections using original checksum and visual comparison. Aggregate previews use its canonical larger rendition, avoiding repeated previews within one results view. Both source affiliations and their unique prompts remain available.

Exact bytes, decoded pixels and recorded hashes across all 738 assets found no proven archive-to-source artwork duplicates. Similar appearance alone was not used to delete images or merge sources.

## Content preference

Two source examples are excluded from normal gallery views, detail routes and image downloads: a kissing couple on a jet ski, and a bikini/ shirtless reclining couple. All 247 archive images remain. Original image files and canonical records are retained in this repository as a backup, so this is a display filter, not secure erasure. Ordinary athletic clothing and a strapless formal dress were retained. See manifests/content-exclusions.json for the review record.
